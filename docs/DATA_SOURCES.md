## 2. Hard Platform Constraints & Truthfulness Rules (V9)

1. **No Fake Metrics & Real Data Only**: If TikTok Creative Center or Meta Ad Library does not disclose verified click counts, private ROAS, or exact dollar spend for commercial ads, SWAI flags those metrics as `UNAVAILABLE` or `null`. Fabricated numbers are strictly forbidden.
2. **Honest Blocked States**: When unauthenticated, SWAI explicitly displays `REQUIRES_AUTH` or `BLOCKED_SOURCE`. Failed discovery requests are NEVER masked with fake synthetic demo ads.
3. **Creative Center Embed Restrictions**: TikTok Creative Center Top Ads detail pages (`/topads/...`) are protected by TikTok security headers and cannot be rendered inside third-party iframes. Only genuine public post permalinks (`tiktok.com/@user/video/...`) are embeddable via `https://www.tiktok.com/player/v1/:id`. For Top Ads, SWAI provides an explicit "Open Original Ad" action.
4. **Search Window vs. Ad Longevity**: An ad appearing under `period=180` in Creative Center filters only indicates the ad ranked within a 180-day search query window. It does NOT prove the ad ran for 180 continuous days. SWAI preserves this distinction in longevity calculations.
5. **Zero-Cost Budget Guard**: Paid providers (Captapi, Apify) are disabled by default. No page navigation, card preview, search input, or automated worker run will trigger metered billing without explicit user authorization.
6. **SSRF Guard**: All outbound provider requests must pass through `executeGuardedProviderRequest()` with hostname validation and private IP range blocking (`127.0.0.1`, `10.0.0.0/8`, `169.254.169.254`, etc.).
