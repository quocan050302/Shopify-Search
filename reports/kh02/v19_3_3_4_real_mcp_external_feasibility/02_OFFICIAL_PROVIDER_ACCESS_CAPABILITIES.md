- [Official BigQuery Trends dataset](https://support.google.com/trends/answer/12764470?hl=en), [sandbox](https://docs.cloud.google.com/bigquery/docs/sandbox). Multi-year historical top-terms coverage does not imply arbitrary-term coverage.

A vendor free plan does not establish this project’s remaining free quota or a target site’s collection permission.

Trends is normalized relative search interest, not orders, absolute searches, revenue, or proven sales. Low-volume zeros and isolated spikes need careful interpretation. Public UI observations do not establish permission for bulk scraping.
